# Health Risk Assessment

A machine learning project that predicts an individual's **health risk level (Low / Medium / High)** based on medical parameters.

The project demonstrates **data preprocessing, exploratory data analysis, and classification modeling** to analyze health indicators and predict potential risk levels.

---

## Tech Stack

![Tech Stack](https://skillicons.dev/icons?i=python,git,mysql)

---

## Key Work Done

- Performed **data preprocessing and cleaning**
- Conducted **Exploratory Data Analysis (EDA)** to identify patterns in health data
- Visualized correlations between health parameters
- Implemented **classification models** for risk prediction
- Evaluated model performance using **accuracy and classification metrics**

---

## ML Techniques Used

- Data Cleaning & Feature Analysis
- Correlation Analysis
- Classification Algorithms
- Model Evaluation

Algorithms explored:
- Logistic Regression
- Decision Tree
- Random Forest

---

## Output

The trained model predicts **health risk categories** based on input medical parameters.

Possible predictions:
- Low Risk
- Medium Risk
- High Risk

---

## Known Limitations

- Limited dataset size may affect prediction performance
- Hyperparameter tuning not extensively explored
- Currently implemented as a **notebook-based prototype**
